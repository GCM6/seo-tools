# S3 内链权重诊断 设计

> 状态:用户授权连续推进(2026-09-29)。依赖 S1 链接图谱(`readLinkGraph`)与 S2 分析层惯例。
> 对应用户原话:"权重是否对"。按 S1 约定理解为**站内链接的权重是否集中到有商业价值的页面**(assumed,用户未纠正),不涉及外链。

## 1. 要回答的问题

| 用户问题 | 规则 | 证据 | claim_type |
|---|---|---|---|
| 有流量/重点页拿到的内链权重够不够? | W01 高价值页内链权重偏低 | 链接图(L4)+ GSC 页面点击/展现(L4)+ 人工重点页标记 | inferred(内部 PageRank 是模型,不是 Google 的真实权重) |
| 权重有没有流向不该拿权重的页? | W02 内链权重集中在低价值页 | 链接图 + 页面 noindex/功能页/零展现 | inferred |
| 重点页的锚文本是否有描述性? | W03 重点页入链锚文本泛化 | 链接明细里的锚文本(L4) | measured_hard(锚文本分布是实测事实);描述里"影响相关性理解"是机制说明 |
| 重点页是否只靠导航/页脚模板链接支撑? | W04 重点页缺少正文上下文内链 | 链接区域(启发式) | inferred(区域是启发式) |

## 2. 非目标

- 不做外链权重、不接第三方 DR/DA。
- 不做"推荐具体从哪一页加链接"的自动生成(建议模板给方法,不给自动改写)。
- 不做区域加权 PageRank 的多方案比较:只实现一个经典 PageRank(阻尼 0.85),区域只用于 W04 的占比统计。

## 3. 计算层(新文件 `lib/crawl/link-equity.ts`,纯函数)

**内部 PageRank**:在 S1 图谱的**可跟随边**上迭代(阻尼 0.85,均匀跳转,悬挂节点——未抓、禁抓、无出链——的质量均匀重分配;迭代至 L1 变化 < 1e-6 或 100 轮)。输出每节点 `rank`(总和 1)与 `percentile`(0–100,按 rank 在**已抓 HTML 节点**中的百分位)。

**覆盖率**:`coverage = 已抓 HTML 节点数 / 图谱节点数`,与 `closureComplete` 一起放进 detail。图谱是抽样(预算截断)时,PageRank 只反映已抓部分的相对结构,规则措辞必须说"在本次抓取的链接图内"。

**高价值页集合**(按优先级取并集):
1. 人工标记的重点页(`isKeyPage`)。
2. GSC:按页面聚合点击(无点击时用展现),取前 20% 且点击 ≥ 1 或展现 ≥ 50 的页面;URL 经 `normalizeUrl` 后用 `nodeFor` 对齐(跳转合并)。
3. 两者都没有 → W01/W03/W04 no-op(不猜哪些页重要)。

**低价值页**:noindex、canonical 指向他页、S2 的功能页(隐私/条款/登录/购物车/搜索…)、分页/标签/归档路径(`/page/N`、`?page=`、`/tag/`、`/category/…/page/`)、以及有 GSC 数据时"近 28 天零展现"的页。

## 4. 规则(新文件 `lib/diagnosis/rules/equity.ts`,支柱 P1,side `technical`)

公共守卫:无图谱 → no-op;入口零出链 → no-op(同 S2);已抓 HTML 节点 < 10 → no-op(样本太小,百分位无意义)。

| 规则 | 命中条件 | 严重度 | detail |
|---|---|---|---|
| W01 | 高价值页中 `percentile < 50` 的页 ≥ 1 | warning | 页 URL、GSC 点击/展现、rank 百分位、入链数、`coverage`、`closureComplete` |
| W02 | 按 rank 排名前 10 的已抓页中,低价值页 ≥ 3 | notice | 这些页的 URL、原因(noindex/功能页/分页/零展现)、合计 rank 占比 |
| W03 | 高价值页的入链中,锚文本为空或属于泛化词表的占比 ≥ 50%(入链 ≥ 3 才判) | notice | 页 URL、泛化占比、锚文本样例 |
| W04 | 高价值页的可跟随入链中,来自 `main` 区域的占比 < 20%(入链 ≥ 3 才判) | notice | 页 URL、区域分布 |

**泛化锚文本词表**(中英):click here、here、read more、learn more、more、details、link、this、查看更多、更多、点击这里、点此、详情、了解更多、阅读更多、查看详情、这里。比较前去空白与标点、转小写。

## 5. UI

站点结构页页面清单新增"内链权重"列(百分位,仅已抓 HTML 页显示);"链接结构"卡片下加一行说明:"内链权重为站内 PageRank 模型估算,仅反映本次抓取的链接结构,不是搜索引擎的真实权重"。

## 6. 版本

`RULES_VERSION` → `rules_v8`(新增 W01–W04)。

## 7. 测试策略

1. `link-equity.test.ts`:PageRank 与手算小图一致(3–4 节点)、质量守恒(总和 1)、悬挂节点重分配、nofollow 不传递、百分位;高价值页集合(GSC 聚合、URL 对齐、跳转合并、无数据时为空);低价值页分类。
2. `equity.test.ts`:W01–W04 命中/不命中/守卫/样本不足。
3. 端到端:扩展 `link-graph.e2e.test.ts` 的假站点,注入 GSC 页面数据,断言 W01 命中一个"有点击但只在第 3 层被一个页面链接"的页。
4. 全量测试 / tsc / lint 不低于 S2 收口基线。

## 8. 风险

- **PageRank 是模型**:Google 的真实权重计算不公开(reported:只有早期论文与专利),本期所有 W 规则只标 inferred,描述不写"Google 给这个页面的权重低"。
- **抽样偏差**:大站只抓 200 页时,PageRank 偏向首页附近。detail 带 `coverage`,覆盖率 < 50% 时描述追加"抓取覆盖不足,结果仅供方向参考"。
- **GSC 未连接**:高价值页只剩人工标记;两者都没有时 W01/W03/W04 不判定,由 UI 引导用户标记重点页或连接 GSC。

## 9. 实现偏离(2026-10-03,已实现,以本节为准)

- **百分位改为相对权重**:真实站点 metadocu.com 冒烟发现,每页互链的扁平站点 PageRank 几乎均匀(最高 0.0513、多数 0.0491,差 4%),百分位却把首页显示成"5"、看似垫底。改用**相对权重 = 该页 PageRank ÷ 已抓 HTML 页中位数**(1.0× 居中)。
  - W01:高价值页相对权重 **< 0.5×** 才命中(原"百分位 < 50")。
  - W02:前 10 名中**相对权重 ≥ 1.5×** 的低价值页 ≥ 3 才命中(扁平站点不误报)。
  - UI"内链权重"列显示 `N.N×`,表头术语说明"0.5× 以下偏低"。
- 低价值页分类排除入口页与高价值页本身。
- GSC 高价值页:有效页(点击 ≥1 或展现 ≥50)中按点击、展现排序取前 20%(向上取整)。
- 计算结果按 (payload, queryPageMetrics) 记忆化,W01–W04 与 UI 共享一次 PageRank。

## 10. 第三轮独立审查后的修订(2026-10-03,已实现)

- 低价值页只认 noindex、canonical 指向他页、分页/标签页;**去掉「零展现」**(GSC 只取前 1000 行 page×query,缺席 ≠ 零展现,无法验证);**功能页不算低价值**(全站链接隐私/条款/登录是正常做法,与 S2 L03、S4 TR06 一致);`?p=` 不算分页(WordPress 文章 ID)。
- 入口页不作为高价值页(W03/W04 曾必然误报首页)。W01 证据引用带上 GSC 证据。GSC 页面对齐兼容百分号编码大小写。
- UI 相对权重 <0.1 显示「<0.1×」;链接结构卡片加内链权重口径说明。
